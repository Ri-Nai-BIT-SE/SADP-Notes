# 基础知识 (Fundamentals)

## 概述

在学习设计模式之前，理解 UML 类图和设计原则是必不可少的。这些基础知识是理解设计模式的理论基础。

### 目录

*   **[UML 类图关系详解](./1-UML类图基础/)**
    *   **核心内容：** 6 种 UML 类图关系的详细说明，包括泛化、实现、组合、聚合、关联、依赖
    *   **学习价值：** 掌握如何通过箭头的形状和线条的虚实来理解类之间的关系
    *   **实践应用：** 结合简单工厂模式等实际案例，帮助理解设计模式类图

*   **[设计原则 (Design Principles)](./2-设计原则/)**
    *   **核心内容：** 涵盖 Head First 设计模式强调的"三大原则"（封装变化、多用组合、针对接口编程）、SOLID 原则以及架构设计原则
    *   **学习价值：** 理解设计模式的理论基础，知道为什么这样设计，而不仅仅是知道如何实现
    *   **实践应用：** 所有设计模式都体现了这些原则，理解原则有助于更好地理解和应用设计模式

---

## 学习建议

1. **先学 UML 类图**：理解类图关系是阅读设计模式类图的基础
2. **再学设计原则**：理解设计原则有助于理解设计模式的设计思想
3. **结合实践**：在学习每个设计模式时，尝试用 UML 类图来理解结构，用设计原则来理解设计思想
