# 软件体系结构风格

软件体系结构风格描述**系统的组织方式**，定义组件、连接件及其约束。

## 风格列表

| 风格 | 核心思想 | 适用场景 |
| :--- | :--- | :--- |
| [管道与过滤器](1-管道与过滤器/index.md) | 数据流经一系列处理步骤 | 数据转换、编译器 |
| [主程序-子程序](2-主程序-子程序/index.md) | 层次化调用结构 | 传统过程式程序 |
| [分层架构](3-分层架构/index.md) | 系统分为若干层，每层只与相邻层交互 | Web 应用、操作系统 |
| [事件系统](4-事件系统/index.md) | 组件通过事件进行隐式调用 | GUI、消息队列 |
| [数据中心/仓库风格](5-数据中心-仓库风格/index.md) | 共享数据存储，组件围绕数据交互 | 数据库系统、IDE |
| [批处理序列](6-批处理序列/index.md) | 顺序执行一系列独立程序 | 数据处理、ETL |
| [客户-服务器模型](7-客户-服务器模型/index.md) | 客户端请求服务，服务器提供服务 | 分布式系统、Web 应用 |
| [面向对象组织](8-面向对象组织/index.md) | 封装数据和操作，通过消息传递交互 | 现代软件系统 |
