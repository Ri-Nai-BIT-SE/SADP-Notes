# 创造型模式

创造型模式关注**对象的创建机制**，将对象的创建与使用分离，使系统更加灵活。

## 模式列表

| 模式 | 核心思想 | 关键词 |
| :--- | :--- | :--- |
| [单例模式](1-单例模式/index.md) | 确保一个类只有一个实例 | 全局唯一、私有构造 |
| [简单工厂](2-简单工厂/index.md) | 由工厂类决定创建哪种产品 | 静态方法、集中创建 |
| [工厂方法模式](3-工厂方法模式/index.md) | 定义创建对象的接口，让子类决定实例化哪个类 | 延迟到子类 |
| [抽象工厂模式](4-抽象工厂模式/index.md) | 创建相关或依赖对象的家族 | 产品族、多个工厂方法 |
