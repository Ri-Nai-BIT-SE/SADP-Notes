# 软件体系结构与设计模式 考试题目（情景分析与实现）

本目录包含软件体系结构与设计模式课程的模拟考试题目，每个题目都包含情景描述、任务要求和参考答案。

#### 题目类型

每道题目通常包含以下类型的任务：

- **画图题**：绘制 UML 类图，展示模式的核心结构
- **代码补全题**：补全关键代码片段
- **简答题**：回答模式的核心概念、问题或解决方案
- **UML 关系分析**：分析类之间的 UML 关系类型

##### 设计模式分类

###### 行为型模式
- 策略模式（题目一）
- 观察者模式（题目二）
- 状态模式（题目七）
- 命令模式（题目九）

###### 结构型模式
- 装饰者模式（题目三）
- 适配器模式（题目六）
- 组合模式（题目八）

###### 创造型模式
- 单例模式（题目四）
- 工厂方法模式（题目五）
- 抽象工厂模式（题目十）
