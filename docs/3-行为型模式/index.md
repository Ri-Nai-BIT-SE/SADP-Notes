# 行为型模式

行为型模式关注**对象之间的通信**，描述对象如何交互和分配职责。

## 模式列表

| 模式 | 核心思想 | 关键词 |
| :--- | :--- | :--- |
| [策略模式](1-策略模式/index.md) | 定义算法族，封装起来，使它们可以互相替换 | 算法替换、组合 |
| [观察者模式](2-观察者模式/index.md) | 定义对象间一对多依赖，状态改变时通知所有依赖者 | 发布-订阅、松耦合 |
| [状态模式](3-状态模式/index.md) | 允许对象在内部状态改变时改变它的行为 | 状态转换、消除条件分支 |
| [解释器模式](4-解释器模式/index.md) | 给定一个语言，定义其文法表示和解释器 | 语法树、递归组合 |
